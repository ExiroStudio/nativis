## 1. Ringkasan Eksekutif (Verdict)

Overnight run pada `overnight/2026-11-23` menghasilkan **perbaikan nyata dan berharga**, terutama memutus penahanan `runtime.shm.lock()` selama `FUTEX_WAIT` (`F-001`), menghapus mutable aliasing `&mut *` lintas thread di FFI (`F-002`), menghilangkan buffer over-read 4× pada `NATIVIS_DEBUG_FORCE_RGBA=1` (`F-009`), membersihkan fitur mati pada `nativis-media` (`F-007`), serta membereskan 100% warning `clippy` dan `rustfmt`.

Namun, **audit membuktikan bahwa sejumlah klaim kunci di `MORNING_REPORT.md`, `FINDINGS.md`, dan `JOURNAL.md` TIDAK AKURAT, BERLEBIHAN (OVERSTATED), atau MENGANDUNG REGRESI BARU**:

1. **P0 "KDE Ghosting/Trail Bug — RESOLVED & PROVEN" (`MORNING_REPORT.md:5`) adalah `OVERSTATED` / `UNVERIFIED` di compositor nyata.**  
   Yang `PROVEN` hanyalah berkurangnya latensi kontensi mutex di unit test sintetis `test_e1_mutex_held_across_futex_wait_blocks_readers` (dan rasio pengurangannya `370.193ms / 4.827µs = 76,692×`, bukan `37,209×`). Plugin hasil build overnight **belum pernah dipasang maupun diuji di sesi `plasmashell 6.7.5` / `kwin 6.7.5` yang sedang berjalan** (`~/.local/share/plasma/wallpapers/com.nativis.wallpaper/` masih berisi `.so` tanggal `Nov 23 20:14`, lebih lama dari build `Nov 24 21:59`).
2. **`F-004` (menghapus `fstat` / `is_valid()` dari `get_shm()`) adalah `REGRESSION [S1]`.**  
   Consumer kini hanya memeriksa `header.magic == NATIVIS_MAGIC` di halaman `mmap` lama (`kde-wayland/plasma-plugin/src/lib.rs:108-128`, `kde-x11/plasma-plugin/src/lib.rs:112-134`), yang tetap bernilai `true` meskipun daemon di-restart atau melakukan resize SHM. Consumer tidak akan pernah reconnect ke `/nativis_shm` baru. Ini diperparah oleh bug lama di `ShmSink::submit()` (`transport-shm/src/lib.rs:239`) yang memanggil `shm_unlink` saat `ShmSurface` lama di-drop *setelah* `ShmSurface` baru dibuka.
3. **`F-005` (`beginExternalCommands`/`endExternalCommands`) dan `F-010` (`TextureCleanupJob`) serta `F-011` (`stopped` flag) di C++ memiliki bug baru (`[S2]`).**  
   `win->endExternalCommands()` terlewat pada dua `early return` di `kde-wayland/nativisitem.cpp:265-268, 404-407` dan dipanggil di `updatePaintNode()` (fase sync, bukan render pass recording). `TextureCleanupJob` membocorkan tekstur jika `window() == nullptr` saat `ItemSceneChange` (detach standar Plasma) serta men-`delete QSGTexture` di GUI thread pada cabang `else`. `stopped: AtomicBool` bisa membuat watcher berputar 100% CPU jika `NativisItem` re-attach dalam kondisi `visible: false` / ukuran `0`.
4. **Bundle `platforms/kde-x11` mengandung mismatch ABI internal (`[S2]`).**  
   `platforms/kde-x11/contents/ui/libnativis_v1_core.so` dibangun ulang pada `2026-11-24 21:59`, tetapi `platforms/kde-x11/contents/ui/libnativisplugin.so` masih artefak usang dari `2026-11-07 13:50` (commit `133f22b`) karena Qt5 dev headers (`Qt5Config.cmake`) tidak terpasang di host.
5. **Klaim P2 soal `vaapi` feature dan `PlanarSlot` "100% hit rate" adalah `FALSE / UNMEASURED`.**  
   `cargo check -p nativis-plugin-video --features vaapi` **gagal** di host (`ERROR: vaapi requested but not found`), dan analisis kode `VideoBackend` membuktikan ada **4 frame hidup bersamaan** (`last_handle` + `cached_frame` + `bounded(1)` + decoder frame #4), yang secara struktural memicu `pool_miss` pada pool 3-slot `Arc::get_mut`.
6. **Inkonsistensi angka & dokumentasi di `.overnight/*.md`:** total test workspace adalah **28** pada **23** paket (`nativis-bootstrapper` memiliki 2 test yang terlewat dari hitungan `26` dan baseline `22`); `Platform Parity Matrix` keliru menandai `Generic Wayland` memakai `transport-shm` (nyatanya memakai WGPU langsung); alasan "headless container" keliru karena host menjalankan sesi live KDE Wayland `6.7.5`; `DECISIONS-NEEDED.md` menyebut versi SHM `2` padahal kode memakai `3`; urutan branch checkpoint terbalik (`checkpoint/p1` & `p2` berada sebelum `checkpoint/p0` dalam sejarah git).

## 3. Bug Tambahan & Ketidaksesuaian Dokumentasi yang Ditemukan Saat Audit

1. **[Pre-existing Compounding S1] `ShmSink::submit()` menghapus `/dev/shm/nativis_shm` saat resize:**
